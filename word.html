Welcome to RetroWord Web

This is a backend-free, browser-based document editor built with open-source JavaScript libraries. It supports rich text formatting, local autosave, importing .docx, .txt, .md, and .html files, plus exporting to HTML and Word-compatible .doc files.

Features

  • Headings, lists, alignment, indentation, colors, links, and images
  • Keyboard shortcuts overlay with F1
  • Responsive page layout and zoom controls
  • Local autosave using browser storage
