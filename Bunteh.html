Shambolic, Jalandhar

The late afternoon sun filters through the dense, ancient canopy of the village banyan tree. The school bell has rung. Bags are dropped. The comforting aroma of evening adrak chai wafts from the courtyard.

Here, on the uneven, dusty earth of the common adda, a different kind of lesson begins. Glass kanche, friendly rivalry, and village pride. Welcome to the traditional game of Dhamuli Marbles.

Game Setup

Traditional Rules

  1. The Pot: All players contribute their marbles to form the pot (max 30).
  2. The Throw: The active player throws all pooled marbles from the palm towards the gitta (hole). Some fall in, others scatter.
  3. The Challenge: The opponents (or game logic) select the hardest scattered marble to hit (farthest from the hole).
  4. The Flick: Drag backwards from your striker marble (like a slingshot) and release to flick it with your thumb and index finger.
  5. Victory: If you hit the challenged target marble, you win all scattered marbles plus those in the hole.
  6. Miss: If you miss or hit a different marble first, you only collect the marbles already in the hole. The scattered marbles remain for the next player.

README & Deployment

Dhamuli Marbles is a AAA-level, single-file HTML5 game built with vanilla JavaScript and Canvas API. No external assets or backend required.

GitHub Pages Deployment:

  1. Create a new public GitHub repository.
  2. Upload this file as index.html.
  3. Go to Repository Settings > Pages.
  4. Set Source to 'Deploy from a branch', select 'main' and '/ (root)'.
  5. Save. Your game will be live at https://yourusername.github.io/repo-name.

Mobile Controls: Tap and drag backwards from the striker marble to aim. Release to flick. Supports multi-touch prevention and haptic feedback.
